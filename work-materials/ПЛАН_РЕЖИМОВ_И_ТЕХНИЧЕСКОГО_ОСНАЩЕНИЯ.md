## Общее оснащение

- Windows-компьютер, стабильный интернет и Android-телефон.
- Желательно второе устройство для сетевого тестирования.
- Git, Node.js 20+, Android Studio, Android SDK, JDK и Python 3.
- Единая рабочая почта, GitHub и Firebase.
- Для iOS-сборки нужен Mac с Xcode или внешний CI-сервис.
- Оплачиваемый собственный сервер на первом этапе не нужен.

## Дворовый футбол

### Офлайн

Игра против ботов, тренировка, кубки, испытания, локальный прогресс и настройки двора. Используются текущие HTML/CSS/JavaScript, localStorage, PWA/Android-кэш и GitHub Pages. Сервер не нужен.

### Игра 1 на 1

WebRTC DataChannel передаёт матч напрямую между игроками. Firebase Realtime Database используется только для комнаты, offer/answer и ICE-кандидатов. Нужны код приглашения, таймер ожидания, переподключение и обработка выхода.

Во время матча передаются действия игрока и небольшие снимки состояния, а не каждый кадр через Firebase. Для сложных сетей может потребоваться TURN-реле.

### Онлайн-турниры

Firebase хранит заявки, пары, статусы матчей и результаты. Сам матч проходит через WebRTC. Первый вариант — дружеские турниры на 4 участника, затем 8 и 16. Для официального рейтинга и защиты от читов понадобится авторитетная серверная проверка.

## Победитель

Онлайн-режим не нужен. Оставить одиночную офлайн-игру, localStorage, локальные достижения и Android-пакет без интернета. Не добавлять комнаты, онлайн-рейтинг и турниры.

## Победитель Junior

Только офлайн. Оставить локальные монеты, предметы, прогресс, родительский шлюз и сброс данных. Не добавлять онлайн-матчи, турниры, публичные имена, чат и сбор детской статистики.

## Рядом

Базовый режим — офлайн: дневник, истории и практики остаются на устройстве. Не добавлять игровые соревнования и рейтинги. Возможные ИИ, голос, места и синхронизация должны быть отдельным защищённым backend-контуром.

## Порядок работ

1. Проверить офлайн-режимы всех приложений.
2. В «Дворовом футболе» сделать один онлайн-режим 1 на 1 по приглашению.
3. Проверить два браузера, две Wi-Fi-сети и мобильную сеть.
4. После этого добавить турнир на 4 участника.
5. Только затем расширять сетку и добавлять модерацию.
