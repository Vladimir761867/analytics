# Экраны и макеты — «У каждого — своё: Большая прогулка» (v0.2)

Интерактивный прототип: [`mockups/index.html`](../mockups/index.html) (онлайн: https://vladimir761867.github.io/To-Each-Their-Own-A-Big-Walk/mockups/).
Скриншоты: [`mockups/shots/`](../mockups/shots/) — `p_*` портрет 390×844, `l_*` ландшафт 844×390, `t_*` планшет 1024×768.

## 0. Общая сетка (для всех экранов)

| Токен | Значение | Комментарий |
|---|---|---|
| Единица масштаба | `cqmin` — 1 % **короткой стороны** экрана | одинаковые пропорции на телефоне и планшете |
| `--btn` | `clamp(64px, 15cqmin, 96px)` | круглая кнопка; ≥ 64 px всегда |
| `--gap` | `clamp(8px, 2.4cqmin, 20px)` | отступ между зонами |
| `--pick` | `clamp(92px, 25cqmin, 200px)` | размер героя-цели |
| `--fs` | `clamp(16px, 4.3cqmin, 28px)` | текст пузыря (2 строки макс.) |
| `--say-h` | `--btn + 14px` | высота пузыря-сообщения |
| Safe-area | `env(safe-area-inset-*)` | фон — на весь экран, интерактив — только внутри |

**Зоны экрана** (сверху вниз внутри safe-area):

```
ПОРТРЕТ                                ЛАНДШАФТ
┌────────────────────────────┐         ┌──────────────────────────────────────────────┐
│ [◀]        HUD        [  ] │ --btn   │ [◀] ( Луми: сообщение …………… 🔊 ) [  ]       │ --btn
│ ( Луми: сообщение … 🔊 )   │ --say-h ├──────────────────────────────────────────────┤
├────────────────────────────┤         │  ЦЕЛЬ / ПРЕДМЕТ   │   ВЫБОР (друзья/лоток)   │
│        ЦЕЛЬ / ПРЕДМЕТ      │ 1fr     │                   │                          │
├────────────────────────────┤         └──────────────────────────────────────────────┘
│   ВЫБОР (друзья / лоток)   │ auto
└────────────────────────────┘
```

- **HUD** (верх): слева «назад/карта», справа — контекстная кнопка (альбом, фото) или пусто. Кнопки фиолетовые с белой обводкой 4 px; главная — коралловая.
- **Пузырь-сообщение** — единственное место для текста. Слева аватар говорящего (имя в тексте не дублируем), затем (на широких экранах) пиктограмма, текст ≤ 3 коротких строк, справа 🔊 (повтор). Новое сообщение **заменяет** старое (анимация «pop» 0,35 с).
- В ландшафте пузырь встаёт **в строку HUD** между кнопками, освобождая высоту под игру.
- **Нижние 20 px и боковые края** — без кнопок (жесты системы).

**Общие состояния целей**: `обычное` → `подсказка` (мягкое жёлтое свечение 1,6 с цикл) → `да` (прыжок + радость + искорки) / `нет` (покачивание ±6° + удивление + облачко со «своим»). В режиме «меньше эффектов» анимации отключены, остаются смена эмоции и свечение-контур без пульса.

## 1. Меню — `screen=menu`
| | Портрет | Ландшафт |
|---|---|---|
| Название | сверху по центру, 10cqmin, белое с контуром-сливой + подзаголовок «светлячковым» | слева, 46 % ширины |
| Герои | «хоровод» 7 друзей вокруг большой Луми (54cqmin) над кнопкой | справа, Луми 56cqmin |
| «Играть» | коралловый круг 1,7×`--btn` (≈110–160 px) внизу по центру, «дышит» | слева под названием |
| Альбом | слева внизу (мятная) | слева внизу |
| Для взрослых | 🔒 справа вверху; **удержание 1,5 с** (кольцо заполняется) → шлюз | так же |

Что происходит: тап по любому герою — его голос и прыжок. Нет текста, который обязательно читать.
При первом запуске «Играть» ведёт на «Цель прогулки», дальше — сразу на карту.
Скриншоты: `p_menu`, `l_menu`, `t_menu`.

## 1а. Цель прогулки — `screen=intro` *(правка 1)*
- Появляется после «Играть» при **первом** запуске; повтор — тап по домику Луми на карте или по фонарику в HUD карты.
- Пузырь (до 3 строк, голос): «У каждого друга есть что-то особенное. Помоги Луми узнать, что именно!» / “Every friend has something special. Help Lumi find out what it is!”
- Сцена: Луми (46cqmin) с качающимся фонариком-звездой; над ней дуга из 7 **тёплых светящихся силуэтов** друзей (19cqmin) со знаком «?» в сливовом кружке.
- Портрет: пузырь → дуга с Луми (1fr) → коралловая ▶ 1,5×`--btn` внизу. Ландшафт: сцена слева, ▶ справа по центру высоты.
- Состояния: силуэты медленно «плавают»; в «меньше эффектов» — статичны.
Скриншоты: `p_intro`, `l_intro`, `t_intro`.

## 2. Карта-маршрут — `screen=map` *(правка 2)*
- **5 зон по тропинке из света**: Домик Луми (старт) → **Лес** (1 Тика, 2 Пипа) → **Пруд** (3 Шелли, 4 Боня) → **Поляна** (5 Жужа, 6 Мими, 7 Тук) → **Большое дерево** (праздник).
- Портрет: зоны — горизонтальные полосы, путь змейкой **снизу вверх** (Домик 88–100 %, Лес 69–88 %, Пруд 48–69 %, Поляна 17–48 %, Дерево 0–17 % высоты игровой области). Ландшафт: зоны — вертикальные колонки, путь **слева направо** (Домик 0–10 %, Лес 10–33 %, Пруд 33–57 %, Поляна 57–89 %, Дерево 89–100 % ширины).
- Декор зон: Лес — ёлки со светлячками и гриб; Пруд — вода и камыши; Поляна — цветы и куст; Дерево — фонарики. Фон зоны — полупрозрачный цветной слой (мята / ручеёк / светлячок-пион).
- Подпись зоны — маленький белый чип (11–17 px), вторичный носитель смысла; в портрете у левого края зоны, в ландшафте — сверху по центру колонки.
- Узлы 1,25×`--btn`: **пройдено** (друг) · **сейчас** (свечение, «дыхание», рядом Луми) · **впереди** (домик в «тумане», нажимается). Старт — будка Луми (`--btn`, тап → «Цель прогулки»). Большое дерево — 1,6×`--btn`.
- HUD: «Меню» · **фонарик** (7 искорок; тап → цель) · «Альбом». Пузыря нет — карта не перегружена текстом.
Скриншоты: `p_map`, `l_map`, `t_map`, `en_l_map`.

## 3. Остановка: «Найди владельца» — `screen=stop&n=0` (Тика, Лес), `n=4` (Жужа, Поляна)
- Предмет в «капле света» 46cqmin; 3 друга `--pick` с именем.
- Тянуть предмет к другу **или** тапнуть друга.
- **Неверно (правка 5)**: друг удивляется, над ним облачко-«пилюля» с **его талантом и вещью**, пузырь — добрая реплика о себе (без имени в тексте — говорящего показывает аватар): «Мур, не моё. Зато я вижу в темноте, как фонарик!». Через 1,5 с правильный друг мягко светится.
- Верно: радость, вещь в облачке, реплика с характером («Мой орешек! Спрячу на потом… Нет — лучше поделюсь!») → через 2,2 с оверлей «Наклейка».
Скриншоты: `p_stop1`, `p_stop1_kind` (неверный выбор — Мими), `en_p_stop1_kind`, и `l_`/`t_` варианты.

## 4. Остановка: «Угадай по звуку» — `screen=stop&n=1` (Пипа, Лес)
- «Ушко» 40cqmin; 3 куста с выглядывающими друзьями.
- Неверный куст: друг выпрыгивает с удивлением и представляется своим звуком: «Это я, Жужа: ж-ж-ж! Я не пою — я жужжу.»; через 2,2 с прячется, «ушко» мягко светится.
Скриншоты: `p_stop2_kind`, `l_stop2_kind`, `t_stop2_kind`.

## 5. Остановка: «У каждого свой талант» — `screen=stop&n=2` (Шелли, Пруд)
- Картинка-ситуация (звёздочка в пруду) + 3 друга со значком таланта.
- Неверно: облачко с талантом + «Плавать не умею, зато перепрыгну любую лужу!» → подсказка.
Скриншоты: `p_stop3_kind`, `l_stop3_kind`, `t_stop3_kind`.

## 6. Остановка: «Собери его мир» — `screen=stop&n=3` (Боня, Пруд), `n=5` (Мими, Поляна) *(правка 4)*
| | Портрет | Ландшафт |
|---|---|---|
| Мир героя (сцена) | центр, до 54cqmin: пунктирный «участок», герой, место для вещи и детали | средняя колонка |
| Слоты: **домик · любимая вещь · особая деталь** | ряд из 3 кругов 1,15×`--btn` (иконки: домик, сердечко, звёздочка) | вертикальная колонка слева |
| Лоток: 2 домика, 2 вещи, 2 детали | 3×2 внизу | 3×2 справа |

- Домик → вырастает фоном (уютная сцена). Вещь → рядом с героем справа внизу. Деталь (цветок / фонарик / флажок / звёздочка) → в своём месте сцены (у входа / на ветке / на крыше / над домиком).
- Неверный домик/вещь: «Ой, это для Пипы! А у меня — норка.» + подсветка правильного варианта в лотке.
- Все три выбраны → реплика с характером («Хрум-хрум! Вот теперь мой мир — мой!») → наклейка. Деталь сохраняется (праздник, альбом).
Скриншоты: `p_stop4` (пусто), `p_stop4_world` (мир собран), `p_stop4_kind` (неверный домик) + `l_`/`t_`.

## 7. Остановка: «Общее дело» — `screen=stop&n=6` (путь к Туку, Поляна)
- 3 карточки (ручей, норка, цветы) — столбиком (портрет) / в ряд (ландшафт); лоток друзей 3×2 / 6 в ряд.
- Неверный помощник — реплика `help` + облачко-талант, нужный друг в лотке светится; верный — реплика `helpYes` («Я — мостик!»), затем вопрос следующего препятствия.
Скриншоты: `p_stop7`, `l_stop7`, `t_stop7`.

## 8. Праздник-итог — `screen=fest` *(правка 3)*
- Ночь, луна, гирлянда, фонарики, полупрозрачное Большое дерево, плед-стол.
- Ряд героев: портрет 2×4 внизу, ландшафт 8 в ряд. **Следующий** мягко светится («выходят по очереди»), но можно нажать любого.
- Тап → герой выходит в центр («сцена»): крупно + сетка до 4 значков того, **что ребёнок о нём узнал** (вещь, домик, талант, звук, особая деталь). Вещь падает на плед, талант — на гирлянду (ряд значков под гирляндой), звук — в музыку. Пузырь — праздничная реплика героя.
- Портрет: сцена над пледом (1fr + auto). Ландшафт: сцена слева, плед справа.
- Все вышли → у каждого облачко с подарком соседа, «Все разные — а вместе веселее!», кнопка «Фото».
Скриншоты: `p_fest` (начало), `p_fest_show` (вышли 5 друзей) + `l_`/`t_`.

## 9. Альбом «Что я узнал» — `screen=album`
- Сетка 2×4 (портрет), 4×2 (ландшафт). Карточка: портрет + 4 наклейки — **вещь, домик, талант, голос**; значок особой детали в углу портрета.
- Наклейка зажигается, когда ребёнок это **узнал** (в т. ч. из доброго ответа на ошибку). Пустые — пунктир, без замков.
Скриншоты: `p_album`, `l_album`, `t_album`.

## 10. Пора отдохнуть — `screen=rest`
- Ночной мир, Луми с закрытыми глазами, пузырь «Луми устала. Отдохнём немножко?».
- Две кнопки: «Домой» (мятная) и «Продолжить» (коралловая). Появляется по таймеру из «Родителям».
Скриншоты: `p_rest`, `l_rest`, `t_rest`.

## 11. Родительский шлюз — `screen=gate`
- Затемнённый мир, белая карточка, **взрослый шрифт** (system-ui).
- Портрет: заголовок, пояснение, пример «7 × 6 = ?», поле ответа, клавиатура 3×4 (кнопки ≥ 56 px). Ландшафт: две колонки (вопрос | клавиатура).
- 1-я ошибка: «Неверно. Осталась 1 попытка». 2-я: блокировка с обратным отсчётом (в игре 60 с, в макете 30 с). Крестик/назад → меню.
Скриншоты: `p_gate`, `l_gate`, `t_gate`.

## 12. Родителям — `screen=parents`
Список настроек (портрет — 1 колонка, ландшафт/планшет — 2): язык (11), музыка, звуки, голоса героев, «меньше эффектов» (Авто/Вкл/Выкл), напоминание об отдыхе (выкл/15/30 мин), **сбросить прогресс** (двухшаговое подтверждение «Точно сбросить? Да/Нет»), политика конфиденциальности (внутри игры), «об игре» (без рекламы/покупок/сбора данных, авторство).
Скриншоты: `p_parents`, `l_parents`, `t_parents`.

## 13. Конфиденциальность — `screen=privacy`
Встроенный текст политики (тот же, что [`privacy.html`](../privacy.html)), прокрутка, кнопка «назад» в «Родителям». Без внешних ссылок.

## Как пользоваться прототипом
- Слева — список экранов, справа — заметки к экрану. Вверху: **Прототип / Арт-бук**, устройство (**Телефон ↕/↔, Планшет ↔/↕**), **RU/EN**, **Меньше эффектов**, **Safe-area** (пунктир безопасной зоны).
- Режим «на весь экран» для проверки реальных размеров: `index.html?bare=1&inset=p&screen=map` (`inset=p|l|t` — эмуляция выреза телефона в портрете/ландшафте и планшета; `demo=N` — N пройденных остановок; `lang=en`; `tap=kitten,home-rabbit` — имитация нажатий, чтобы показать состояние).
- Звук включается после первого касания (политика браузеров).
- Скриншоты пересобираются одной командой: `bash tools/shots.sh` (Chrome headless → WebP).
