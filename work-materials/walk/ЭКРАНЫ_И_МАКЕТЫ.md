# Экраны и макеты — «У каждого — своё: Большая прогулка»

Интерактивный прототип: [`mockups/index.html`](../mockups/index.html) (онлайн: https://vladimir761867.github.io/To-Each-Their-Own-A-Big-Walk/mockups/).
Скриншоты: [`mockups/shots/`](../mockups/shots/) — `p_*` портрет 390×844, `l_*` ландшафт 844×390, `t_*` планшет 1024×768.

## 0. Общая сетка (для всех экранов)

| Токен | Значение | Комментарий |
|---|---|---|
| Единица масштаба | `cqmin` — 1 % **короткой стороны** экрана | одинаковые пропорции на телефоне и планшете |
| `--btn` | `clamp(64px, 15cqmin, 96px)` | круглая кнопка; ≥ 64 px всегда |
| `--gap` | `clamp(8px, 2.4cqmin, 20px)` | отступ между зонами |
| `--pick` | `clamp(92px, 25cqmin, 200px)` | размер героя-цели |
| `--fs` | `clamp(16px, 4.3cqmin, 28px)` | текст пузыря (2 строки макс.) |
| `--say-h` | `--btn + 14px` | высота пузыря-сообщения |
| Safe-area | `env(safe-area-inset-*)` | фон — на весь экран, интерактив — только внутри |

**Зоны экрана** (сверху вниз внутри safe-area):

```
ПОРТРЕТ                                ЛАНДШАФТ
┌────────────────────────────┐         ┌──────────────────────────────────────────────┐
│ [◀]        HUD        [  ] │ --btn   │ [◀] ( Луми: сообщение …………… 🔊 ) [  ]       │ --btn
│ ( Луми: сообщение … 🔊 )   │ --say-h ├──────────────────────────────────────────────┤
├────────────────────────────┤         │  ЦЕЛЬ / ПРЕДМЕТ   │   ВЫБОР (друзья/лоток)   │
│        ЦЕЛЬ / ПРЕДМЕТ      │ 1fr     │                   │                          │
├────────────────────────────┤         └──────────────────────────────────────────────┘
│   ВЫБОР (друзья / лоток)   │ auto
└────────────────────────────┘
```

- **HUD** (верх): слева «назад/карта», справа — контекстная кнопка (альбом, фото) или пусто. Кнопки фиолетовые с белой обводкой 4 px; главная — коралловая.
- **Пузырь-сообщение** — единственное место для текста. Слева аватар говорящего, затем (на широких экранах) пиктограмма, текст ≤ 2 строк, справа 🔊 (повтор). Новое сообщение **заменяет** старое (анимация «pop» 0,35 с).
- В ландшафте пузырь встаёт **в строку HUD** между кнопками, освобождая высоту под игру.
- **Нижние 20 px и боковые края** — без кнопок (жесты системы).

**Общие состояния целей**: `обычное` → `подсказка` (мягкое жёлтое свечение 1,6 с цикл) → `да` (прыжок + радость + искорки) / `нет` (покачивание ±6° + удивление + облачко со «своим»). В режиме «меньше эффектов» анимации отключены, остаются смена эмоции и свечение-контур без пульса.

## 1. Меню — `screen=menu`
| | Портрет | Ландшафт |
|---|---|---|
| Название | сверху по центру, 10cqmin, белое с контуром-сливой + подзаголовок «светлячковым» | слева, 46 % ширины |
| Герои | «хоровод» 7 друзей вокруг большой Луми (54cqmin) над кнопкой | справа, Луми 56cqmin |
| «Играть» | коралловый круг 1,7×`--btn` (≈110–160 px) внизу по центру, «дышит» | слева под названием |
| Альбом | слева внизу (мятная) | слева внизу |
| Для взрослых | 🔒 справа вверху; **удержание 1,5 с** (кольцо заполняется) → шлюз | так же |

Что происходит: тап по любому герою — его голос и прыжок. Нет текста, который обязательно читать.
Скриншоты: `p_menu`, `l_menu`, `t_menu`.

## 2. Карта прогулки — `screen=map`
- Портрет: тропинка-змейка **снизу вверх** (остановки 1→7, затем Большое дерево сверху). Ландшафт: **волна слева направо**.
- Тропинка: широкая полупрозрачная светлая лента + пунктир «искорок».
- Узел-домик 1,25×`--btn`: состояния **пройдено** (белый круг, друг машет) · **сейчас** (жёлтое свечение, «дыхание», рядом Луми) · **впереди** (домик в «тумане», полупрозрачный — но нажимается).
- HUD: слева «Меню», по центру **фонарик Луми** (7 искорок прогресса), справа «Альбом».
- Сообщений нет (Луми на текущем узле подпрыгивает — подсказка «иди сюда»). При первом входе — голос: «Куда пойдём? Нажми на светящийся кружок».
Скриншоты: `p_map`, `l_map`, `t_map`.

## 3. Остановка: «Найди владельца» — `screen=stop&n=0` (Тика), `n=4` (Жужа)
- Цель: предмет в «капле света» 46cqmin (ландшафт 40cqmin), плавно «плавает».
- Выбор: 3 друга `--pick` с подписью-именем (подпись вторична).
- Действие: перетащить предмет на друга **или** тапнуть друга.
- Неверно: друг → эмоция «удивление», облачко с **его** предметом, пузырь: «Мими: „Не моё! У меня — клубок“».
- Верно: «радость», предмет у хозяина в облачке, искорки, мелодия → через 1,5 с оверлей **«Наклейка»** (наклейка 40cqmin + кнопки «Альбом» и «Дальше»).
- Подсказка: 2 ошибки или 7 с — свечение правильного друга.
Скриншоты: `p_stop1`, `l_stop1`, `t_stop1`, `en_p_stop1` (английский).

## 4. Остановка: «Собери героя» — `screen=stop&n=1` (Боня), `n=5` (Мими)
| | Портрет | Ландшафт |
|---|---|---|
| Герой | центр, до 54cqmin | средняя колонка |
| Слоты (дом / любимое / украшение) | ряд из 3 кругов 1,15×`--btn` под героем | вертикальная колонка слева |
| Лоток (6 вариантов) | сетка 3×2 внизу | сетка 3×2 справа |

- Домик: верный появляется фоном за героем; неверный — «Я живу не тут!» + свечение слота.
- Любимое: «Это не моё любимое!».
- Украшение: любое, надевается на голову/шею, герой радуется.
- Все 3 слота заполнены → «Готово! Боня идёт с нами!» → наклейка.
Скриншоты: `p_stop2`, `l_stop2`, `t_stop2`.

## 5. Остановка: «Угадай по звуку» — `screen=stop&n=2` (Пипа)
- Цель: большая кнопка-«ушко» 40cqmin с расходящимися кольцами.
- Выбор: 3 куста, из которых в такт звуку выглядывают ушки/хохолки.
- Тап по кусту: друг выпрыгивает; неверный говорит своим голосом и прячется через 1,6 с.
Скриншоты: `p_stop3`, `l_stop3`, `t_stop3`.

## 6. Остановка: «У каждого свой талант» — `screen=stop&n=3` (Шелли)
- Цель: картинка ситуации (пруд со звёздочкой).
- Выбор: 3 друга, у каждого **значок таланта** в белом кружке на плече.
- Неверно: «Боня: „Не я. Зато я высоко прыгаю!“» + значок таланта в пузыре.
Скриншоты: `p_stop4`, `l_stop4`, `t_stop4`.

## 7. Остановка: «Общее дело» — `screen=stop&n=6` (Тук)
| | Портрет | Ландшафт |
|---|---|---|
| Препятствия | 3 карточки **столбиком** (ручей, норка, цветы) | 3 карточки **в ряд** |
| Помощник | пустой кружок справа в карточке | под картинкой |
| Лоток друзей | 3×2 внизу | 6 в ряд внизу |

- Активная карточка — жёлтая рамка; пройденная — белая с помощником-радостью; Луми переходит к следующей.
- Пузырь всегда содержит **только текущий вопрос** («Тёмная норка! Кто видит в темноте?»).
- Финал: «Прошли все вместе! А вот и Тук с яблоком!» → наклейка → **Праздник**.
Скриншоты: `p_stop7`, `l_stop7`, `t_stop7`.

## 8. Праздник — `screen=fest`
- Ночная палитра, луна, гирлянда, 4 фонарика (покачиваются), Большое дерево, плед.
- Герои: портрет — 2 ряда по 4 внизу; ландшафт — 8 в ряд.
- Тап по герою → его вещь на плед, его партия в музыку, радость. После всех 8 — у каждого облачко с подарком соседа, «Все разные — а вместе веселее!», в HUD справа появляется коралловая кнопка **«Фото»**.
Скриншоты: `p_fest`, `l_fest`, `t_fest`.

## 9. Альбом друзей — `screen=album`
- Сетка карточек: портрет 2×4, планшет-портрет 3 колонки, ландшафт 4×2.
- Карточка: портрет героя + 3 наклейки-кружка (предмет, домик, талант). Не встреченные — нежный силуэт и пунктирные кружки (без замков).
- Тап по встреченному — голос и искорки.
Скриншоты: `p_album`, `l_album`, `t_album`.

## 10. Пора отдохнуть — `screen=rest`
- Ночной мир, Луми с закрытыми глазами, пузырь «Луми устала. Отдохнём немножко?».
- Две кнопки: «Домой» (мятная) и «Продолжить» (коралловая). Появляется по таймеру из «Родителям».
Скриншоты: `p_rest`, `l_rest`, `t_rest`.

## 11. Родительский шлюз — `screen=gate`
- Затемнённый мир, белая карточка, **взрослый шрифт** (system-ui).
- Портрет: заголовок, пояснение, пример «7 × 6 = ?», поле ответа, клавиатура 3×4 (кнопки ≥ 56 px). Ландшафт: две колонки (вопрос | клавиатура).
- 1-я ошибка: «Неверно. Осталась 1 попытка». 2-я: блокировка с обратным отсчётом (в игре 60 с, в макете 30 с). Крестик/назад → меню.
Скриншоты: `p_gate`, `l_gate`, `t_gate`.

## 12. Родителям — `screen=parents`
Список настроек (портрет — 1 колонка, ландшафт/планшет — 2): язык (11), музыка, звуки, голоса героев, «меньше эффектов» (Авто/Вкл/Выкл), напоминание об отдыхе (выкл/15/30 мин), **сбросить прогресс** (двухшаговое подтверждение «Точно сбросить? Да/Нет»), политика конфиденциальности (внутри игры), «об игре» (без рекламы/покупок/сбора данных, авторство).
Скриншоты: `p_parents`, `l_parents`, `t_parents`.

## 13. Конфиденциальность — `screen=privacy`
Встроенный текст политики (тот же, что [`privacy.html`](../privacy.html)), прокрутка, кнопка «назад» в «Родителям». Без внешних ссылок.

## Как пользоваться прототипом
- Слева — список экранов, справа — заметки к экрану. Вверху: **Прототип / Арт-бук**, устройство (**Телефон ↕/↔, Планшет ↔/↕**), **RU/EN**, **Меньше эффектов**, **Safe-area** (пунктир безопасной зоны).
- Режим «на весь экран» для проверки реальных размеров: `index.html?bare=1&inset=p&screen=map` (`inset=p|l|t` — эмуляция выреза телефона в портрете/ландшафте и планшета; `demo=N` — N пройденных остановок; `lang=en`).
- Звук включается после первого касания (политика браузеров).
- Скриншоты пересобираются: `bash tools/shots.sh` (PNG), затем конвертация в WebP (см. README).
